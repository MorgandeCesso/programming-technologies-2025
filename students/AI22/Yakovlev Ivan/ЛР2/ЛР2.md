async def message_handler(message: Message) -> None:

```python (utils/gpt.py)
async def get_response(message: str, client: AsyncOpenAI, name: str, user_id: int) -> str:
    try:        
        save_message(user_id, "user", message)
        history = get_recent_messages(user_id, limit=6)
        messages = []
        if system_prompt:
            messages.append({"role": "system", "content": system_prompt})
            messages.append({"role": "system", "content": f"Ты общаешься с пользователем по имени {name}. Обращайся к нему по имени."})
        messages.append({"role": "user", "content": message})
        messages.extend(history)
        response = await client.responses.create(
            model="gpt-4.1-nano",
            input=messages
        )
        answer = response.output_text
        save_message(user_id, "assistant", answer)
        return answer
    except Exception as e:
        logging.error(f"Error occurred: {e}")
        print(e)
        return f"Произошла ошибка при получении ответа: {e}"
```
Имя пользователя добавляется в промпт с указанием обращаться по имени.

##  Хранение сообщений в базе данных

Используемая СУБД: SQLite (файл chat_history.db).
Таблица messages:
id (первичный ключ), user_id, role (user/assistant), content, timestamp.
Индекс по (user_id, timestamp DESC) для быстрой выборки.
Функции:
init_db() – создаёт таблицу и индекс.
save_message() – сохраняет сообщение.
get_recent_messages(limit=6) – возвращает последние записей пользователя (в хронологии).
clear_context() – удаляет все сообщения пользователя.
Роль: обеспечивает сохранение контекста диалога (последние 6 сообщений) и возможность его сброса командой /reset-context.
